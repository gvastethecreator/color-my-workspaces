# Security

This extension writes workspace settings only (`workbench.colorCustomizations` and `workspaceColor.*`). It does not send data off the machine.

If you find a vulnerability, do not open a public issue with exploit details. When the GitHub repository exists, use a private security advisory. Until then, contact the maintainer through their GitHub profile: [gvastethecreator](https://github.com/gvastethecreator).
